# Hotel López García · Sabores de Latinoamérica

Sitio web responsivo sin dependencias de compilación.

## Iniciar
Abrir `index.html` en el navegador o publicar desde `main` con GitHub Pages (Settings → Pages → Deploy from a branch → main/root).

## Importante
La distribución propuesta es de 34 NK1, 33 NQQ y 33 suites: pendiente de confirmación. Amenidades y fotografías son ilustrativas.

Las reservas se solicitan por WhatsApp; no se confirman ni bloquean habitaciones. El concierge es un asistente automático de preguntas frecuentes sin IA generativa ni backend. Para disponibilidad real y chatbot basado en IA deben integrarse los servicios externos correspondientes.
